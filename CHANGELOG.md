# Changelog

All notable changes to Mosaicora for WordPress are documented here.

The project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-07-30

### Added

- Added deterministic Mosaicora Open Graph and X image metadata for indexable
  WordPress views.
- Added global settings, cache rotation, setup diagnostics, and an image preview.
- Added guided, typed Mosaicora v3 overrides for block and classic editors.
- Added page-level disable, cache revision, and template controls.
- Added safely serialized WebPage JSON-LD for pages with overrides.
- Added per-site Multisite settings, optional uninstall cleanup, translations,
  developer filters, automated tests, and WordPress.org-ready packaging.
- Licensed the plugin under Apache License 2.0, matching the Mosaicora PHP core.
